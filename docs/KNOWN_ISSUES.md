# 已知问题

当前开发版本为 **0.3.6（未发布）**。以下区分已观察到的限制与尚未充分验证的范围；请使用已备份或可丢弃的文档。

## 已观察到的问题与限制

- **代码块拼音退出保存：**使用系统简体拼音，候选尚未确认时按 `⌘Q`，曾将原始拼音保存到磁盘。历史问题仍未解决，根因未确定；后续成功不能证明根因已修复。建议退出前先确认候选，核对“已保存”及文件内容；重要文档保留备份。不能单靠是否出现候选窗判断保存正确。
- **查找替换与撤销：**曾观察到连续快捷键后未恢复替换前文本，历史失败根因仍未确定。查找输入框有独立的撤销行为；需要撤销正文替换时，先按 Esc 关闭查找并返回正文，再撤销、保存及核对文件内容。输入框处理撤销本身不代表路由错误。
- **内存占用：**200 MB 目标尚未达到。多标签、混合内容及某些弹层操作占用偏高；单标签触发 Quick Open 后也可能超过预算，关闭全部标签后也不保证立即回收。尚不能确认或排除长期泄漏，部分操作阶段的额外增长仍未归因。目前没有保证达标的规避方式，应留意系统内存压力。
- **跨模式撤销：**源码模式与可视化编辑的撤销历史不统一。实际修改源码后返回可视化编辑会建立新的撤销边界；未改动或精确还原源码则保留原历史。切换前可保存或复制内容；标签内可复制的源码编辑前检查点只在会话中存在，不是持久备份。
- **Markdown 格式：**可视化编辑可能规范化列表、围栏、表格和硬换行等格式，未承诺整篇字节级无损。需要精确保留源码格式时使用源码模式，并核对保存差异。
- **光标绘制：**WebKit 在少数软换行边界可能显示位置不理想的光标；已有观察未发现内容、选区或修改状态受影响，暂无通用规避方式。

## 尚未充分验证

- 查找替换、撤销／重做、保存与完整重开已通过正常 Release 的小文档原生自动化检查；真人分步及 Esc 连续快捷键场景仅在诊断构建中通过。替换准备期间取消的原生时序仍未覆盖，相关取消及迟到结果隔离由确定性测试覆盖；这些结果不证明历史失败根因已修复。
- 原生实机验证以 Apple Silicon、macOS 27 系列为主；Intel 和 macOS 13–26 缺少实机覆盖。支持 macOS 13+ 及提供双架构安装包不等于所有平台均已验收。
- 连续逐帧原生画面证据不足，不能排除短暂白屏，也不能据此认定存在白屏。部分 Dock、应用切换、最小化恢复和触控板惯性滚动行为仍缺可靠原生验证。
- VoiceOver 实际朗读仍待真人验证；名称、角色及键盘检查不能代替实际朗读。Typora 尚无同机比较数据，不作全面性能或体验优劣结论。

浏览器模拟或合成输入不能代替原生文件系统与真人输入法验证。开发与诊断约束见[开发指南](DEVELOPMENT.md)。
